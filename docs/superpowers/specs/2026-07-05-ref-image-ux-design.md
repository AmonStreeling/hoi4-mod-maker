# 参考底图 UX 改版设计

日期：2026-07-05
状态：已获用户批准（含样式图确认）
样式图：https://claude.ai/code/artifact/3a979421-da51-4dda-9e81-1e69909f6866

## 需求

陆地绘制页面"① 参考底图"卡片的四点改进：

1. **导入按钮置顶** — 「导入参考图…」放到卡片第一行。
2. **打开原版参考** — 卡片内新增按钮，一键从游戏目录加载原版地图（复用文件菜单的 `_on_load_vanilla_ref` 逻辑），不用翻菜单。
3. **两张图各自定制** — 原版参考图补齐缩放滑条 + 铺满按钮 + 拖拽能力，与自定义图完全对称（现状：原版图强制拉伸铺满，只能调透明度）。
4. **调整模式拖拽** — 新增「调整参考图位置」开关按钮；激活期间左键拖动 = 移动参考图、滚轮 = 缩放参考图，**一切绘制功能暂停**；ESC 或再点一次退出。

## 卡片布局（改版后）

```
① 参考底图
[导入参考图…(蓝描边)] [打开原版参考]
─ 原版参考 ──────────── [隐藏]
  透明度 ▬▬▬ 30%
  缩放  ▬▬▬ 100%  [铺满]
─ 自定义参考图 ────────── [隐藏]
  透明度 ▬▬▬ 40%
  缩放  ▬▬▬ 100%  [铺满]
[🖐 调整参考图位置]（开关）
调整对象: (•)自定义 ( )原版   ← 平时置灰，激活后可用
提示行（小字）
```

## 调整模式行为

- 开关按钮激活后变**橙色**（`#f97316`，与变换工具 checked 一致），文字变为"正在调整参考图（点击或 ESC 退出）"。
- 画布上被调整的参考图显示**橙色虚线边框**，光标变移动样式（SizeAllCursor）。
- 输入拦截：左键拖动移动选中参考图；滚轮缩放它（同步回页面滑条）；画笔/填充/省份点击/框选等全部不触发；中键/空格平移视图保留。
- 退出：再点按钮或按 ESC → 恢复正常绘制，虚线框隐藏。
- 「调整对象」单选决定拖拽/滚轮作用于自定义图还是原版图。
- 原有 Ctrl+左键拖拽 / Ctrl+滚轮缩放（作用于自定义图）保留不变。

## 实现结构

| 文件 | 改动 |
|------|------|
| `views/canvas/ref_images.py` | 重构：抽出通用"参考图层"结构（item + 原始 pixmap + scale），原版/自定义各一份，统一 load / opacity / scale / move / fit / visible 接口。旧方法名保留为薄包装，main_window 接线与现有测试不动。 |
| `views/canvas/widget.py` | `_vanilla_ref_item` 初始化处适配新结构；新增调整模式状态 + 虚线框 QGraphicsRectItem。 |
| `views/canvas/input_router.py` | mousePress/Move/Release/wheel 顶部拦截调整模式；ESC 退出（发信号让页面按钮取消勾选）。 |
| `features/map/land/page.py` | 卡片重排 + 新控件 + 新信号：`open_vanilla_requested`、`adjust_mode_toggled(bool)`、`adjust_target_changed(str)`、原版缩放/铺满信号。 |
| `views/main_window.py` | 新信号接线到 canvas / file_ops。 |
| `ui/i18n/{zh,en,ru}/land.py` | 新文案 key（先中文，英/俄按 i18n 工作流补）。 |

## 验证

- `pytest` 全量（page 信号接口向后兼容，旧测试应全过）。
- 手动 GUI：调整模式下画笔无效、拖拽/滚轮生效、ESC 退出恢复绘制；原版图可缩放拖拽；「铺满」复位。

## 风险

- input_router 事件分支多（15+），调整模式拦截必须放在所有绘制分支之前，漏一个分支就会"调整时误画"。对策：拦截放 mousePressEvent 最顶部（仅次于中键平移）。
- ref_images 重构改内部属性名，widget.py 里散落的 `_vanilla_ref_item` 引用需全部同步。
